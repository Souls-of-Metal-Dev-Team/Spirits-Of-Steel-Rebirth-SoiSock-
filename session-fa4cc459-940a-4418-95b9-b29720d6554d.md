## Shape of the migration

Keep all `Node`/`Control`/`AStar2D` classes in Godot (UI, `MapContainer`, `SoiStar`, `GameClock`, the autoloads). Extract a plain `Microsoft.NET.Sdk` library — `Sosr.Core`, `net8.0`, no Godot reference — containing the data POCOs, serialization tree, diff/merge, RNG, and pure sim logic. Godot's `.csproj` adds a `ProjectReference` and becomes the host/adapter that owns file I/O (`res://`, `FileAccess`) and scene wiring. Keep the `Sosr` namespace in the core so most call sites need no `using` changes.

The cheapest seam: **core deals only in JSON strings and a canonical `object?` tree** (`Dictionary<string, object?>`, `List<object?>`, `double` for every number). Godot's `MapData.LoadJSON`/`SaveJSON` keep reading/writing files and hand text across. No filesystem or path abstraction needed.
